# Spot the Error
#### Video Demo: https://youtu.be/tNbq1PWM7xg
#### Description:
Spot the Error is an interactive Python terminal game where players are challenged to find mistakes hidden inside short code snippets. Each puzzle presents a small piece of Python code that contains a deliberate bug, such as a wrong operator, inconsistent indentation, a variable naming issue, or an index that is out of range. The player’s task is to carefully read through the snippet and identify the type of error.

The motivation behind this project was to create a simple yet effective way to practice debugging. Beginners often struggle to recognize common programming mistakes when first learning Python, so this game provides a focused environment to practice those skills. Instead of being overwhelmed by a large program, the player looks at small, controlled examples that highlight specific mistakes.

The gameplay loop is straightforward: the user is shown a code snippet, they make a guess about the type of error, and the program provides feedback. If the guess is correct, the player can move on to the next challenge; if it is wrong, the program will indicate that the answer is incorrect and give the player a chance to try again. Over time, this repetition helps train the player’s eye to spot issues more quickly and accurately.

Features:
- A curated collection of Python code snippets, each containing a deliberate bug.
- Feedback when the user selects an incorrect answer, encouraging them to think carefully before retrying.
- An expandable puzzle set, making it easy to add new challenges without rewriting the main logic.
- Clear, beginner-friendly interface that works entirely in the terminal.

This project was built as my CS50 Final Project. It uses simple Python logic and a lightweight structure to demonstrate how programming concepts can be turned into an engaging learning tool. My goal was to make a project that is not only functional but also educational, encouraging players to improve their coding and debugging skills in a fun, game-like setting. In the future, this project could be expanded into a web-based version with more interactivity, levels of difficulty, and a larger library of puzzles.

In the future, when I have more coding experience, I would love to expand on this project by turning it into a fully interactive web application where users can click the incorrect line directly. I also imagine adding leaderboards with scores, as well as daily changing snippets of code to keep the game fresh and competitive.
